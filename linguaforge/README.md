# LinguaForge

Браузерное расширение, которое **проверяет и исправляет текст на нужном языке**,
объясняет ошибки **на твоём родном языке** и помогает **с переводом**, когда ты
застрял. Что-то среднее между Grammarly и DeepL, но с акцентом на пояснения «почему
так, а не иначе» — как у хорошего репетитора.

Движок — [Claude](https://www.anthropic.com/) (по умолчанию `claude-opus-4-8`).

---

## Что умеет (MVP)

- Пишешь или вставляешь текст → расширение находит ошибки (грамматика, орфография,
  выбор слова, пунктуация, стиль, естественность) и **объясняет каждую на родном языке**.
- Даёт исправленный, естественно звучащий вариант на целевом языке (в один клик копируется).
- Если текст написан на родном языке — переводит его на целевой.
- Кнопка «Вставить выделенное» подхватывает текст, выделенный на странице.
- Настраиваемые: модель, родной язык, целевой язык, тон (нейтральный / формальный / дружеский).

## Установка

Сборка не нужна — это обычные файлы.

1. Открой `chrome://extensions` (работает в Chrome, Edge, Brave и других на Chromium).
2. Включи **Режим разработчика** (Developer mode).
3. Нажми **Загрузить распакованное расширение** (Load unpacked) и выбери папку
   `linguaforge/` (ту, где лежит `manifest.json`).
4. Открой настройки расширения и вставь свой **API-ключ Anthropic**
   (получить — на [console.anthropic.com](https://console.anthropic.com)).
   Нажми «Проверить ключ», чтобы убедиться, что всё работает.

После этого жми на иконку LinguaForge, пиши текст и нажимай «Проверить»
(или `Ctrl/Cmd + Enter`).

---

## Приватность

- API-ключ и настройки хранятся **только в твоём браузере** (`chrome.storage.local`).
- Текст уходит **напрямую** в `api.anthropic.com` и больше никуда — промежуточного
  сервера нет.
- Расширение читает текст со страницы только когда ты сам нажимаешь
  «Вставить выделенное» (разрешение `activeTab`, без постоянного доступа ко всем страницам).

## Структура проекта

```
linguaforge/
├── manifest.json            # Manifest V3
├── icons/                   # иконки 16/32/48/128
└── src/
    ├── background.js        # service worker: единственное место с ключом и вызовом API
    ├── lib/
    │   ├── anthropic.js     # вызов Claude Messages API (fetch) — вся сеть здесь
    │   ├── prompt.js        # системный промпт + JSON-схема ответа (мозг продукта)
    │   └── storage.js       # настройки и значения по умолчанию
    ├── popup/               # всплывающее окно (основной интерфейс)
    └── options/             # страница настроек
```

Вся «сеть» изолирована в `src/lib/anthropic.js`, а вся «логика проверки» — в
`src/lib/prompt.js`. Менять поведение модели или способ вызова можно, не трогая UI.

### Почему `fetch`, а не официальный SDK

Расширение работает в service worker'е Manifest V3 без шага сборки, поэтому вызов API
сделан простым `fetch` с заголовком `anthropic-dangerous-direct-browser-access`. Это
позволяет грузить расширение как есть, без `npm`/бандлера. Если позже понадобится
официальный `@anthropic-ai/sdk` или собственный бэкенд-прокси (чтобы не держать ключ в
браузере) — менять нужно только `src/lib/anthropic.js`.
